# Smart DIY 裝機助手

純 Vue 3 響應式網頁，電腦工作區與手機直式介面自動適配。Python 獨立負責 FastAPI、LangChain/LangGraph Agent、RAG、京東爬蟲、對話與任務持久化；Java 保留帳號、硬體、配置單、社群、資訊等業務，管理端使用 Element Plus。

原 uni-app 與 Java AI／行情模組已移除。現有業務 MySQL 可繼續使用；舊 AI 對話、記憶及設定有明確匯入腳本，不自動刪除歷史資料表。

啟動、部署及測試方式請參閱[主要文件](../README.md)與[Python 服務文件](../smart-diy-pc-assistant-agent/README.md)。
