## 本次交付行为

1. PC 导航默认收起为图标栏，可展开；选中背景按实际按钮位置上下滑动。
2. 对话历史默认显示在主界面，可独立收起、恢复。手机以主界面内的历史区域显示。
3. PC 右侧显示真实工具调用、开始/完成、计划、商品结果和时间戳；窄屏通过执行记录抽屉查看。
4. 历史会话从后端回放所有轮次的执行事件，SSE 用于实时追加；没有生成模拟的工具记录。
5. 导航、分段选择、登录/注册、收藏分类、需求选项、移动底栏统一使用 `v-slider`，300ms 滑动；路由和登录表单切换使用渐变。
6. 未登录时使用默认人像图标，头像内没有“我”字。
7. PC 输入区固定可见，长对话在内容区滚动；手机恢复原版独立登录、资料、设置、详情和反馈等页面结构。
8. 京东解析兼容 `goods-pc-filter-upgrade`，修复相对图片路径，按类目过滤整机/板 U 套装；未知价格和库存不作推断。后台 Agent 配置页新增抓取测试入口。
